# Pub Menu Magic

Мне нужен одностраничный сайт для паба в виде меню с возможностью генерации QR кода для этого сайта, в тёмном стиле, чтобы были следующие пункты меню: алкоголь, коктейли, безалкогольные напитки, закуски к пиву, основные блюда, блюда для компании, первые блюда, , бургеры, гарниры, холодные закуски, салаты, кофе и чай, десерты. Сайт на двух языках - русском и румынском. Мне нужны возможности добавить подпункты меню для групп блюд, чтобы была видна миниатюра блюда/напитка. Так же, мне нужна возможность добавлять варианты к пункту меню, например, для пива 0.5 и 0.3. Интуитивно понятная админ панель так же нужна.
